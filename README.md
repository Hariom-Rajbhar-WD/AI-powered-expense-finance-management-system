# Finance AI

A full-stack personal finance management application built using React, Node.js, Express and MongoDB.

## Features

- User registration
- User login
- JWT authentication
- Expense management
- Expense categories
- Budget management
- Expense analytics
- Charts
- AI finance advisor
- Responsive UI

## Tech Stack

### Frontend

- React
- React Router
- Axios
- Recharts
- Lucide React

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

## Run Backend

```bash
cd backend
npm install
npm run dev
